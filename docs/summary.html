01

The search pipeline

Every index shares one path: compress vectors to a small code for a fast approximate scan, keep the best k·oversample candidates, then re-score those with exact full-precision distances. Coarse selection is cheap; accuracy is recovered on a tiny shortlist.

encode
Quantize
f32 → int8 / 1-bit / PQ codes. 4×–32× smaller, cache-friendly.
scan
Approx distance
SIMD dot/L2 over codes (AVX2 · wasm v128), bounded top-k heap.
refine
Rerank
Re-score the shortlist with exact f32 → final top-k.
02

Indexes

how candidates are narrowed before scanning
exact-ish

Flat

Brute-force int8 scan + f32 rerank. Simple, SIMD-bound, recall 1.0 to hundreds of thousands of vectors.

nprobe

IVF

k-means++ cells; scan only the nprobe nearest. Best recall/throughput balance.

graph

HNSW

Multi-layer proximity graph with the diversity heuristic. Highest throughput at high recall.

graph · ¼ mem

int8-HNSW

Same graph, int8 nodes (~¼ the vector memory). Built & searched in quantized space, f32-reranked.

03

Quantizers

how each vector is compressed
4×

int8 scalar

Per-vector symmetric quantization. The safe default — recall stays ~1.0 with rerank.

32×

binary 1-bit

Sign bits + Hamming. Collapses on non-negative data — a cautionary baseline for RaBitQ.

32×

RaBitQ

Rotation + sign code + an unbiased inner-product estimator. 1-bit storage, far higher recall.

32×

IVF+RaBitQ

Per-cell centroids keep residuals tight — where RaBitQ's estimator shines.

up to 32×

PQ

Subspace split + per-subspace codebooks + ADC lookup-table scan. 16 bytes/vector at m=16.

32×

IVF+PQ

Residual PQ per cell — the classic billion-scale index. Tight codes, high recall.

rotated

OPQ

Learned orthonormal rotation (self-contained Jacobi SVD) balances subspaces before PQ.
